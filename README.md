# Portfolio Site
A simple HTML CSS website about myself and my work.

This website has 3 pages:
- Home
- About
- Contact

Website is based on Black & White theme with Red `<a>` tags.

Its too simple and I just made it in a hurry but will surely update it in future!

## Work in the site
I have used static HTML and CSS in this project, no Javascript for now. I tried making it responsive also, still learning more things. I have been a backend developer for a year and now also trying frontend, with a good progress.

I will keep updating this site more often when I learn more about frontend.
